# AgentX

Multi-platform AI agent dashboard — a concept.

Idea: one dashboard to manage AI assistants answering on WhatsApp and Telegram (powered by Groq-hosted LLaMA models).

## Status

Concept stage. Not deployed, no code released yet.

## Why it exists

The thinking behind it lives inside the [NOVA](https://whispering-nova-ai-hub.base44.app) super app, which already does multi-platform AI. This repo is the exploration ground for a standalone dashboard.
